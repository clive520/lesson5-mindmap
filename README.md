# 國語五上 第5課《最好的味覺禮物》心智圖教學簡報系統

本專案將國語五上第5課《最好的味覺禮物》全班 19 張學生心智圖作業，結合 **3 種不同風格設計的模範心智圖（幾何標準、童趣手繪插畫、大自然生命樹意象）**，製作成支援全螢幕投影片放映、上一張/下一張切換、風格切換、四象限平滑縮放聚焦、並排多風格對照，以及逐張缺點與結構分析的互動式多模態教學簡報系統。

🔗 **線上瀏覽網址 (GitHub Pages)**:  
👉 **https://clive520.github.io/lesson5-mindmap/**

## 🌟 核心特色與心智圖三大風格

### 🎨 三大風格模範心智圖（支援即時切換與 SVG 向量下載）
針對課文內容與學童多元智慧發展需求，設計了三款完全不同視角與表現手法的心智圖：

1. **📐 幾何標準結構（方形四象限平衡版 · `square_mindmap.svg`）**：
   * **特色**：以 1200×1100 正方比例佈局，打破 NotebookLM 長條版過於狹長細小的缺點。
   * **色彩區隔**：琥珀金黃（鳳梨汁）、翠綠薄荷（芭樂汁）、紫紅寶石（李子果醬）、晴空天藍（教育初衷與哲思）。
   * **教學價值**：示範正規「中心主題 ➔ 一級主幹 ➔ 二級分支 ➔ 2~4字關鍵詞」的清晰放射網絡。

2. **🎨 童趣手繪插畫風（圖文筆記 Sketchnote · `illustrated_mindmap.svg`）**：
   * **特色**：結合課文情境量身繪製手繪微插圖，如 🍍 鳳梨切片與果汁機雪白泡沫奶泡、🍈 爸爸抽獎箱與香氣音符、🍒 大熬煮鍋焦糖氣泡與手工李子果醬罐、🌱 泥土萌芽幼苗與 ☀️ 太陽 🌙 星空。
   * **認知理論**：運用**雙重編碼理論 (Dual Coding)**，透過圖文聯結活化學童右腦形象思維，大幅提高記憶提取效率。
   * **教學價值**：讓心智圖轉變為生動的圖像繪本筆記，鼓勵孩子在筆記中加入與文本緊密結合的塗鴉。

3. **🌿 大自然生命樹意象（生態有機結構 · `tree_mindmap.svg`）**：
   * **特色**：呼應課文第四段「閉上眼睛想像植物從泥土裡生成、陽光下甜蜜、黑夜中堅強」核心哲思。
   * **隱喻架構**：
     * **樹根扎入土壤**：象徵食材源於大地（🌱 從泥土裡生成）。
     * **粗壯主幹**：象徵守護孩子的味覺、抵禦街頭化學添加物麻痺。
     * **果樹枝枒與碩果**：向右伸展金鑽鳳梨果枝、向左伸展童年芭樂果枝、向上伸展紫紅李子果枝。
     * **樹梢頂端金黃大果**：結出「🎁 自己動手做是最好的味覺禮物」之深層生命意境。
   * **教學價值**：引導高年級學生體會「心智圖可以有生命隱喻」，打破冰冷方塊，展現深刻的文本哲思。

## 🕹️ 互動功能與鍵盤快捷鍵

* **風格切換快捷鍵**：
  * `Z`：切換至 **📐 幾何標準結構**
  * `X`：切換至 **🎨 童趣手繪插畫風**
  * `C`：切換至 **🌿 大自然生命樹意象**
* **象限縮放與導覽快捷鍵**：
  * `0`：回到全圖總覽視角
  * `1`：放大聚焦第一象限（🍍 手作鳳梨汁）
  * `2`：放大聚焦第二象限（🍈 童年芭樂汁）
  * `3`：放大聚焦第三象限（🍒 熬煮李子果醬）
  * `4`：放大聚焦第四象限（🌿 教育初衷與哲思）
* **投影與評析控制**：
  * `←` / `→` / `空白鍵`：上一張 / 下一張
  * `S`：開啟 / 關閉**並排標準圖對照模式**（可輪播對照 4 種圖樣）
  * `D`：展開 / 收合**右側評析與教學提示面板**
  * `T`：展開**底部全 26 張投影片縮圖抽屜**
  * `F`：全螢幕放映模式
  * `R`：手動順時針旋轉圖片 90°
  * `+` / `=`：手動放大影像

## 🛠️ 本地開啟與離線使用

本專案採用純原生前端技術（HTML5 + CSS3 + 模組化 SVG 向量圖），完全無任何外部 npm 依賴套件，下載後**雙擊 `index.html` 即可直接在任何瀏覽器中離線順暢運行**。

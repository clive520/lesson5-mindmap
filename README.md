# 國語五上 第5課《最好的味覺禮物》心智圖教學簡報系統

本專案將國語五上第5課《最好的味覺禮物》全班 19 張學生心智圖作業，結合 **依據原版標準方形架構所設計的「課文主題插畫豐富版」與「幾何標準版」模範心智圖**，製作成支援全螢幕投影片放映、上一張/下一張切換、風格切換、四象限平滑縮放聚焦、並排多風格對照，以及逐張缺點與結構分析的互動式多模態教學簡報系統。

🔗 **線上瀏覽網址 (GitHub Pages)**:  
👉 **https://clive520.github.io/lesson5-mindmap/**

## 🌟 模範心智圖核心設計理念

為避免傳統結構過於擁擠重疊、或是因樹狀枝枒頂端集中導致放大局部象限時內容被裁切的問題，本系統以 **1200×1100 四象限平衡放射拓撲結構** 為基底，提供兩種切換風格：

### 1. 📐 風格一：幾何標準版（`square_mindmap.svg`）
* **設計特點**：純淨俐落的幾何圓角卡片與漸層平滑連線。
* **色彩系統**：琥珀金黃（鳳梨汁）、翠綠薄荷（芭樂汁）、紫紅寶石（李子果醬）、晴空天藍（教育初衷與哲思）。
* **教學價值**：示範正規「中心主題 ➔ 一級主幹 ➔ 二級分支 ➔ 2~4字關鍵詞」的清晰層級網絡，徹底破除學生將課文整句照抄的通病。

### 2. 🎨 風格二：課文主題手繪插畫點綴版（`illustrated_mindmap.svg`）
* **設計特點**：**完全保留幾何標準心智圖乾淨清晰、絕不重疊的四象限架構與文字大小**，摒棄生硬的矩形框架，以溫暖靈動的**手繪風格小插畫（Hand-drawn Doodles）**自由點綴在各分支與中央主題周圍：
  * 🍍 **右上象限（手作鳳梨汁）**：手繪鮮採金鑽鳳梨與切片、高速果汁機攪打漩渦、高腳杯雪白綿密泡沫與紅白條紋吸管。
  * 🍈 **左上象限（童年芭樂汁記憶）**：爸爸復古手搖抽獎箱（「🎉 幸運中獎!」中獎籤）、黃綠熟軟芭樂切片、滿室芬芳果香旋風音符 `♫ ♪` 與溫馨果汁杯。
  * 🍒 **左下象限（熬煮李子果醬）**：鮮豔暗紅李子串、逗趣「酸得皺眉 (>_<)」表情塗鴉、滾燙焦糖氣泡大熬煮鍋、小木湯匙試吃（⭐**建立味覺自信**）、手作布蓋果醬罐。
  * 🌿 **右下象限（教育初衷與哲思）**：遠離市售化學茶飲、肥沃泥土破土而出的綠芽 🌱、盛開小花 🌸、暖陽甜蜜 ☀️、星空黑夜堅強 🌙✨、精緻禮物盒 🎁（動手做是最好的禮物）。
  * 🌟 **中央主題節點**：正上方手繪主廚帽 👨‍🍳 與迷你水果星光點綴，增添溫馨童趣。
* **無損局部放大**：無論是全圖檢視或是放大聚焦到單一象限，**文字節點與對應的手繪插畫皆能 100% 完整呈現於螢幕正中央，毫無重疊死角**！

## 🕹️ 互動功能與鍵盤快捷鍵

* **風格切換快捷鍵**：
  * `Z`：切換至 **📐 幾何標準結構**
  * `X`：切換至 **🎨 課文主題插畫豐富版**
* **象限縮放與導覽快捷鍵**：
  * `0`：回到全圖總覽視角
  * `1`：放大聚焦第一象限（🍍 手作鳳梨汁）
  * `2`：放大聚焦第二象限（🍈 童年芭樂汁）
  * `3`：放大聚焦第三象限（🍒 熬煮李子果醬）
  * `4`：放大聚焦第四象限（🌿 教育初衷與哲思）
* **投影與評析控制**：
  * `←` / `→` / `空白鍵`：上一張 / 下一張
  * `S`：開啟 / 關閉**並排標準圖對照模式**（可輪流切換對照標準版、插畫豐富版、原版長條圖）
  * `D`：展開 / 收合**右側評析與教學提示面板**
  * `T`：展開**底部全 25 張投影片縮圖抽屜**
  * `F`：全螢幕放映模式
  * `R`：手動順時針旋轉圖片 90°
  * `+` / `=`：手動放大影像

## 🛠️ 本地開啟與離線使用

本專案採用純原生前端技術（HTML5 + CSS3 + 模組化 SVG 向量圖），完全無任何外部 npm 依賴套件，下載後**雙擊 `index.html` 即可直接在任何瀏覽器中離線順暢運行**。

# 國語五上 第5課《最好的味覺禮物》心智圖作業簡報與深度評析

本專案將國語五上第5課《最好的味覺禮物》全班 19 張學生心智圖作業，製作成支援全螢幕投影片放映、上一張/下一張切換、並排標準圖對比（NotebookLM 心智圖），以及逐張缺點與結構分析的互動式教學簡報系統。

🔗 **線上瀏覽網址 (GitHub Pages)**:  
👉 **https://clive520.github.io/lesson5-mindmap/**

---

## 🌟 核心功能

* 🖥️ **近全螢幕放映**：自適應圖片容器，支援瀏覽器全螢幕放映（按 `F` 鍵）。
* ⬅️➡️ **極簡導覽切換**：
  * 畫面兩側懸浮大箭頭 `‹` / `›`
  * 底部懸浮工具列
  * 鍵盤快捷鍵：`←` / `→`、`空白鍵`、`PageUp` / `PageDown`、`Home` / `End`
  * 支援手機與平板觸控左右滑動 (Swipe)
* 🌟 **全新！模範心智圖（第 20 ~ 24 張投影片 · 方形四象限結構）**：
  * **方形結構改善**：突破原 NotebookLM 長條垂直心智圖過於狹長、字體偏小的限制，採用 **1200×1100 方形四象限放射結構**，全圖視野開闊大器。
  * **全圖與局部聚焦雙模式**：
    * **第 20 張**：🌟 模範心智圖全圖總覽（快捷鍵 `0`）
    * **第 21 張**：🍍 示範解析一 · 手作鳳梨汁（第一象限放大聚焦，快捷鍵 `1`）
    * **第 22 張**：🍈 示範解析二 · 童年芭樂汁記憶（第二象限放大聚焦，快捷鍵 `2`）
    * **第 23 張**：🍒 示範解析三 · 熬煮李子果醬（第三象限放大聚焦，亮點：⭐建立味覺自信，快捷鍵 `3`）
    * **第 24 張**：🌿 示範解析四 · 手作初衷與教育意義（第四象限放大聚焦，亮點：泥土/陽光/黑夜生命哲思，快捷鍵 `4`）
  * **互動相機平滑平移（Smooth ViewBox Pan & Zoom）**：在投影片內點擊上方藥丸標籤或點擊心智圖分支群組，鏡頭自動滑順聚焦放大，無損向量文字清晰無比。
  * **支援向量原檔下載**：內建「下載心智圖」按鈕，可直接下載完整高畫質 `square_mindmap.svg` 檔。
* 📝 **缺點剖析與導讀面板 (按 `D` 鍵)**：
  * 學生作業（第 1~19 張）：展示作品概況、老師紅筆評語、對照標準圖缺漏要點、格式結構缺陷、具體改進建議。
  * 模範解析（第 20~24 張）：展示架構定位說明、課堂教學引導重點、關鍵詞提煉示範、全班常見錯誤導正建議。
* ⚖️ **並排標準圖對比 (按 `S` 鍵)**：
  * 支援左側學生作業、右側標準心智圖分割畫面，並可即時切換「方形結構」或「原版長條結構」進行對照。
* 🔄 **智慧校正與縮放 (按 `R` / `+` / `0` 鍵)**：
  * 針對側向拍攝之照片已完成無損轉正，支援旋轉與放大檢視。
* 📑 **縮圖抽屜導覽 (按 `T` 鍵)**：
  * 一鍵展開全 24 張投影片縮圖列表，含 5 張模範色彩徽章卡，快速點選跳頁。
* 📊 **全班共通缺失診斷報告**：
  * 匯總全班 5 大共通思維與繪製盲點（關鍵詞提煉不足、結構扁平、誤用心智圖為流程圖/大綱、深層哲理意象缺漏、格線拘束）。

四大核心主支脈絡標準：

  • 一、手作鳳梨汁：
    • 準備材料：有機金鑽鳳梨、開水
    • 製作步驟：切掉鳳梨頭與削皮 ➔ 除去鳳梨心並切塊 ➔ 裝進玻璃缸備用 ➔ 倒入果汁機攪打
    • 成品特徵：淺黃色果汁、上方覆蓋雪白泡沫
  • 二、童年芭樂汁記憶：
    • 契機：爸爸抽獎帶回果汁機
    • 製作過程：市場買回黃綠色軟芭樂 ➔ 洗淨切成小塊狀 ➔ 整盤投入玻璃容器
    • 成品特色：芭樂香氣濃郁、轉瞬間成為好喝果汁
  • 三、熬煮李子果醬：
    • 李子特性：外觀暗紅美麗、口感酸得讓人皺眉、大人遊說對皮膚好
    • 熬煮流程：搬出最大鍋子開火 ➔ 切開李子取果核 ➔ 加入一包黃砂糖熬煮
    • 熬煮互動：果肉融化混合焦糖 ➔ 小湯匙舀出嘗味道 ➔ 建立小小味覺自信 ➔ 熄火冷卻後裝瓶
  • 四、手作初衷與教育意義：
    • 擔憂現象：隨處可見的茶飲店、化學氣味與色素麻痺味覺
    • 引導想像植物生成：從泥土裡生成 ➔ 開花之後結果 ➔ 陽光照射變甜蜜 ➔ 黑夜星空變堅強
    • 核心價值：嘗一嘗食物真正的味道、自己家裡熬的果醬最好吃、自己動手做是最好的味覺禮物

📊 全班 19 份心智圖作業診斷報告與共通缺失

🚨 共通缺失 1：關鍵詞提煉不足，整句甚至整段抄錄

多位學生（如第3、7、10、17張）直接將課文長句塞在節點上，違反心智圖「關鍵字（1~4字）」的基本原則，導致畫面擁擠，失去網絡快速提取記憶的功能。老師甚至直接在第3張批註「字再精簡」。

🚨 共通缺失 2：結構層級扁平，缺乏二級、三級次節點展開

超過 60% 的學生只有一層放射線，主幹末端直接連一個方框寫一句話，未將「材料、步驟、感官特質、情感意義」有層次地逐層展開。

🚨 共通缺失 3：心智圖形式被誤用為流程圖、作文大綱或表格

例如第8張被寫成「國語語文結構與修辭分析筆記」；第12、13張被寫成「起因、經過、結果」的故事敘事大綱；第16張更是直接寫成條列式段落筆記（完全沒有心智圖結構）。

🚨 共通缺失 4：深層意涵與哲思意象幾乎全數缺漏

絕大多數學生僅著重在「製作果汁/果醬」，但課文後半段最動人的「閉眼想像植物從泥土生成、在陽光下甜蜜、黑夜中堅強」之教育理念，以及「建立孩子味覺自信」，在學生作品中幾乎全數遺漏！

🚨 共通缺失 5：受限於格線作業簿的條框思維

學生在國語作業簿橫線或直行格子上作畫，常受限於既有格線，形成由上而下的列隊式書寫，壓抑了放射狀思考的自由度。
